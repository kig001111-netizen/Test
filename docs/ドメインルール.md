# ドメインルール（最終版）

> 目的: ELDEN RING NIGHTREIGN の **火力計算**（Excel と同じ結果）を最優先する。  
> **Excel の計算結果を Single Source of Truth とする。**  
> 計算結果は SQLite に保存せず、毎回 `DamageCalculator` で再計算する。

---

## 1. アプリの位置づけ

| 項目 | 内容 |
|---|---|
| 本質 | 火力計算ツール（ビルドシミュレーター） |
| 正解の定義 | Excel（ナイトレイン遺物付帯計算器）の計算結果 |
| 永続化の役割 | 効果マスタ・所持遺物・ビルド構成の保存のみ |
| 計算の扱い | 毎回 `DamageCalculator` → `CalculationResult`。DB には残さない |

---

## 2. 業務ルール

### 2.1 遺物（Relic）

| ルール | 内容 |
|---|---|
| 名前 | 必ず持つ |
| 色 | 必ず持つ（UI・検索・識別用） |
| 効果数 | **3スロット**（SlotNumber = 1〜3） |
| 効果の選択 | **効果マスタ（Effect）から選択** |
| 複数登録 | **同一内容の遺物を複数件登録してよい**（それぞれ別 `Relic.Id`） |
| 複数装備 | **同一 `RelicId` を1ビルド内の複数 Position に装備してよい** |
| メモ | 任意。計算対象外 |

### 2.2 効果（Effect）

| ルール | 内容 |
|---|---|
| 名称 | 必ず持つ |
| 倍率（Value） | 必ず持つ（例: 1.04。百分率ではない） |
| 重複可否（CanStack） | `true` = 同一 EffectId でも複数可 / `false` = **同一 EffectId のみ** 1 回 |
| Level | 通常は 1。段階効果のみ 2 以上 |
| EffectId | +値違いは別 ID。段階効果（同一名称・複数 Level）は **共通 EffectId**（Excel 先頭 ID） |
| DisplayOrder | **UI の表示順のみ**。計算順・優先度には使わない |
| マスタ出典 | `個人開発マスタ.xlsx`（倍率は Value として保持） |
| 段階効果 | 封牢・夜の侵入・攻撃連続時などは **遺物では1効果**。計算画面で Level を指定 |
| Priority / StackGroup / CalculationStage | **持たない・不要** |

### 2.3 重複判定（Effect 単位）

- 判定は **Relic 単位ではなく Effect 単位**
- `CanStack = true` → 同一 EffectId でも全件採用
- `CanStack = false` → **同一 EffectId のみ**先頭1件を採用。EffectId が異なれば併用可
- StackGroup は使用しない

### 2.4 ビルド（Build）

| ルール | 内容 |
|---|---|
| 構成 | 遺物 **6個**（Position = 1〜6） |
| 同一遺物 | 同じ `RelicId` を複数 Position に割り当て可能 |
| 保存・読込 | 名前・キャラ名・武器名・遺物スロット構成を保存／復元できる |
| 武器表示火力 | ビルド保存対象外（画面入力の一時値） |

### 2.5 計算（DamageCalculator）

| 手順 | 内容 |
|---|---|
| 1 | Effect 一覧を入力する（Relic は扱わない） |
| 2 | DuplicateChecker |
| 3 | 条件判定（現段階は全件通過） |
| 4 | Level に応じた Value 取得 |
| 5 | 適用対象 Value をすべて乗算 |
| 6 | 最終火力 = 武器表示火力 × 全倍率 |
| 7 | CalculationResult 生成 |

制約:

- Excel と不一致なら実装を直す（Excel が正解）
- `DisplayOrder` は計算順に使わない
- Priority / CalculationStage / StackGroup は導入しない

## 3. 保存対象（SQLite）

| テーブル | 保存内容 |
|---|---|
| Effect | Id(行PK), EffectId, Name, Category, CanStack, Value, Level, Description, DisplayOrder |
| Relic | Id, Name, Color, Memo, CreatedAt, UpdatedAt |
| RelicEffect | RelicId, EffectId, SlotNumber |
| Build | Id, Name, CharacterName, WeaponName, CreatedAt, UpdatedAt |
| BuildRelic | BuildId, RelicId, Position |

---

## 4. 保存対象外

| 項目 | 生成元 |
|---|---|
| 最終火力 / 最終倍率 | `CalculationResult` |
| 適用された効果一覧 | `CalculationResult` |
| 無効化された効果一覧 | `CalculationResult` |
| 重複判定結果 | `CalculationResult` |
| 計算ログ | `CalculationResult` |
| 一時計算データ | `DamageCalculator` 内部 |
| 基礎攻撃力 | 画面の一時入力 |

---

## 5. 各クラスの責務

| クラス | 責務 | 禁止事項 |
|---|---|---|
| Effect / Relic / Build 等 Model | 属性の保持 | 計算ロジック |
| CalculationRequest | 計算入力の受け渡し | DB アクセス |
| CalculationResult | 計算出力（非永続） | DB 保存 |
| Repository | CRUD | 火力計算・重複判定 |
| SqliteInitializer | DB 生成・テーブル・Seed | UI・計算 |
| Relic/Effect/Build Service | ユースケース（登録・検索・保存） | Excel 乗算の詳細実装 |
| **DamageCalculator** | 重複判定・Excel 順乗算・最終火力・ログ | DB アクセス・UI |
| Form | 入出力 | SQL・計算式の直書き |

```
[画面] 基礎攻撃力 / ビルド選択
   → [BuildService] 構成組み立て
   → [DamageCalculator] 重複判定 + Excel順乗算
   → [CalculationResult] を画面表示
```

---

## 6. 採用方針サマリ

| 項目 | 最終方針 |
|---|---|
| 同一遺物の複数登録 | **可** |
| 同一遺物の複数装備 | **可** |
| 重複判定の単位 | **EffectId**（CanStack） |
| Priority | **不要** |
| 計算順 | **Excel = 正解。DamageCalculator が管理** |
| Effect | **データのみ** |
| DisplayOrder | **UI 表示順のみ** |
